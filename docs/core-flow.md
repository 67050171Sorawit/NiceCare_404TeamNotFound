# Core Flow
## Sprint Goal

ใน Sprint 3 ทีมเราจะพัฒนาระบบไฟอัจฉริยะให้สามารถใช้งานได้จริง  
เพื่อสร้างต้นแบบ Smart Home สำหรับผู้สูงอายุที่สามารถทดสอบการทำงานได้จริงภายในบ้าน

---
ผู้สูงอายุเดินผ่านบริเวณภายในบ้าน  
⬇️  
ระบบตรวจจับการเคลื่อนไหวแบบเรียลไทม์  
⬇️  
ระบบสั่งเปิดไฟอัตโนมัติทันที  
⬇️  
ผู้สูงอายุสามารถเดินภายในบ้านได้อย่างปลอดภัยและสะดวกมากขึ้น

---

## รายละเอียดของ Flow

| หัวข้อ | รายละเอียด |
| --- | --- |
| ผู้ใช้หลักของ Flow | ผู้สูงอายุที่อยู่บ้านตามลำพัง |
| Input ของระบบ | การเคลื่อนไหวของผู้สูงอายุภายในบ้าน |
| กระบวนการทำงานของระบบ | ตรวจจับการเคลื่อนไหว และสั่งเปิด-ปิดไฟอัตโนมัติแบบเรียลไทม์ |
| Output ที่ผู้ใช้ได้รับ | ไฟเปิดอัตโนมัติเมื่อมีการเดินผ่าน |
| จุดประสงค์สำคัญของ Flow | เพิ่มความปลอดภัย ลดความเสี่ยงในการสะดุดหรือล้ม และช่วยอำนวยความสะดวกในการใช้งานภายในบ้าน |

---

## จุดเด่นของระบบ

- เปิดไฟอัตโนมัติแบบ Real-time
- ลดความเสี่ยงในการเกิดอุบัติเหตุภายในบ้าน
- ช่วยให้ผู้สูงอายุใช้งานพื้นที่ภายในบ้านได้สะดวกขึ้น
- รองรับการใช้งานสำหรับผู้สูงอายุที่อยู่ลำพัง
- เป็นฟังก์ชันหลัก (Core Function) ของระบบ NiceCare

---

## Expected Outcome

ระบบสามารถช่วยให้ผู้สูงอายุเคลื่อนไหวภายในบ้านได้อย่างปลอดภัยมากขึ้น  
พร้อมเพิ่มความสะดวกสบายในการใช้ชีวิตประจำวันผ่านระบบอัตโนมัติ
