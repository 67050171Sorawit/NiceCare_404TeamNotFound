## Top Insights
Insight 1: Readability มีผลต่อความอุ่นใจ : ความหนาบางที่ไม่สม่ำเสมอของตัวอักษรสนับสนุนบนหน้าจอ ไม่ใช่แค่เรื่องความสวยงาม แต่ทำให้ผู้ดูแลสับสน เสียเวลาเพ่ง และลดทอนความน่าเชื่อถือของหน้า Dashboard ฉุกเฉิน
Insight 2: ผู้ดูแลต้องการ "ทางไปต่อ (Actionable Next Step)": เมื่อหน้าจอร้องเตือนเหตุวิกฤต (Fall Detected) จิตวิทยาของผู้ดูแลจะอยู่ในสภาวะตื่นตระหนก การแสดงแค่ตัวหนังสือเตือนภัยยังไม่พอ ระบบต้องป้อนทางเลือกเชิงรุก เช่น "ปุ่มโทรด่วนหาโรงพยาบาล" ขึ้นมาให้ทันที
Insight 3: Label ปุ่มเตือนภัยต้องเคลียร์ 100%: ปุ่มฉุกเฉินหรือปุ่ม SOS ที่กำกวม (เช่น ผู้ใช้ไม่แน่ใจว่ากดแล้วระบบจะทำอะไรต่อ) จะทำให้ผู้ดูแลลังเลที่จะกดในจังหวะวิกฤต label ต้องเปลี่ยนเป็นคำสั่งเชิงพฤติกรรมที่ชัดเจน
